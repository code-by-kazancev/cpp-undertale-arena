# ⚔️ C++ Boss Arena (атмосфера Undertale)

Делаю консольную арену с механиками, вдохновленными Undertale.

Изначально написал всё в одном файле, чтобы просто проверить, как работает плавный ввод, игровой цикл и отрисовка. Механики заработали, но код быстро превратился в кашу из гигантского **switch** и десятков переменных, передаваемых по ссылке. Стало понятно: в таком виде развивать проект дальше не получится.

## 🎮 Что внутри

**Этап 1 — Прототип:** Плавное движение, фаза предупреждения и базовые атаки (снаряды, волны, осколки) через `enum` и `switch`.

**Этап 2 — Полиморфизм (текущая версия):** Переписал систему атак на ООП. Каждая атака — отдельный класс, `AttackManager` управляет ими через `vector<unique_ptr<Attack>>`. Добавлены защита от случайного выхода и стабильная отрисовка без мерцания.

📜 ***Подробную историю изменений с примерами кода смотрите во вкладке `Commits`.***

## 📋 Планы на будущее (Этап 3)
Разнести классы по отдельным `.h` и `.cpp` файлам, чтобы не держать сотни строк в одном `main.cpp` и соблюдать принцип единой ответственности (SRP) на уровне файловой системы.

## 🛠️ Стек
`C++17`, STL (`<memory>`, `<vector>`, `<chrono>`, `<string>`), ООП (полиморфизм, инкапсуляция), базовый WinAPI для консоли.

## 🚀 Как запустить
Просто открой `main.cpp` в Visual Studio (или любой другой IDE), убедись, что стандарт C++17 включён, и жми Run. Сторонних библиотек не требуется.
