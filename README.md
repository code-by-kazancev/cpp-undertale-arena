# ⚔️ C++ Boss Arena (атмосфера Undertale)

Делаю консольную арену с механиками, вдохновленными Undertale.

Изначально написал всё в одном файле, чтобы просто проверить, как работает плавный ввод, игровой цикл и отрисовка. Механики заработали, но код быстро превратился в кашу из гигантского **switch** и десятков переменных, передаваемых по ссылке. Стало понятно: в таком виде развивать проект дальше не получится.

## 🎮 Что внутри (на этапе прототипа)
- Плавное движение персонажа (WASD) без блокировки ввода.
- Фаза предупреждения перед ударом.
- Снаряды, волны и осколки, управляемые через `enum` и `switch`.

## 📋 Планы на будущее
Хочу разобраться, как правильно применять полиморфизм в игровом цикле, и переписать систему атак так, чтобы каждая атака была отдельным классом. Заодно научиться использовать умные указатели вместо ручной работы с памятью. А после этого — разнести всё по отдельным файлам, чтобы не держать сотни строк в одном месте.

## 🛠️ Стек
`C++17`, стандартная библиотека (STL), базовый WinAPI для консоли.

## 🚀 Как запустить
Просто открой `main.cpp` в Visual Studio (или любом другом IDE), убедись, что стандарт C++17 включён, и жми Run. Сторонних библиотек не требуется.
